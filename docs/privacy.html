Privacy policy

This is a private, single-owner deployment of gmail-mcp. It connects the owner's own Gmail accounts to the owner's own AI assistant. It is not offered to the public, and only addresses on the owner's allowlist can sign in.

What it accesses

With the owner's consent, it uses Google's Gmail API to read, search, label, archive and draft messages in the signed-in mailbox. A separate, supervised copy can also move messages to Trash and remove labels and drafts. Neither copy can send mail.

Where data goes

Mail content passes only between Google and the owner's assistant, through this server. It is not stored, sold, shared, used for advertising or used to train AI models. Google sign-in tokens are kept encrypted in the owner's own Cloudflare account and are never logged.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access ends when the account's access is removed at Google Account, Third-party connections. Stored tokens then stop working and are discarded.
